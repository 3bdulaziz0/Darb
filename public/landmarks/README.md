# صور المعالم — Landmark photos

**كل معلم له مجلد هنا باسم الـ`id` حقّه.** حط صور المعلم في مجلده، شغّل أمرًا
واحدًا، وخلاص. ما تعدّل أي ملف كود، ولا تعدّل `landmarks.json` بيدك.

Every landmark has a folder here named after its `id`. Drop the photos in,
run one command, done. No code edits, and never edit `landmarks.json` by hand.

---

## الطريقة · How to add photos

**1.** لقّط المجلد الصحيح — اسمه نفس الـ`id`:

```
public/landmarks/lm_masmak/
public/landmarks/lm_riyadh_the_saudi_national_museum/
```

**2.** حط الصور جوّه. أي أسماء تمشي، بس الترقيم أوضح:

```
public/landmarks/lm_masmak/
  1.jpg
  2.jpg
  3.jpg
```

**3.** علّم المعلم بأنه جاهز للاختبار في `landmarks.json`:

```json
"test_ready": true
```

**4.** شغّل:

```bash
npm run photos
```

**الصور وحدها لا تكفي.** السكربت يربط صور المعالم المعلَّمة `test_ready` فقط.
هذا مقصود: إسقاط مجلد صور يجب ألا يوسّع مجموعة الاختبار من غير قرار بشري.
المعالم غير المعلَّمة تبقى صورها على القرص بلا ربط، والسكربت يخبرك بعددها.

الأمر يقرأ المجلدات، ويكتب مسارات الصور في `landmarks.json` تلقائيًا، ويطبع
تقريرًا بكم معلم صار عنده صور وكم باقي.

**أول صورة في المجلد** تصير هي الصورة اللي تظهر في القائمة وفي صفحة القصة،
فخلّها أحسن وحدة عندك.

---

## كيف تكون الصورة مفيدة للتعرّف

الـAI بيقارن صورة الزائر بهذي الصور. فالهدف مو صورة جميلة — الهدف صورة
**تعرّف**. المعيار: لو شفت هالصورة بروحها، تقدر تميّز المبنى عن أي مبنى ثاني
يشبهه؟

**٣ صور على الأقل، من زوايا مختلفة:**

| # | الزاوية | ليه |
|---|---|---|
| 1 | الواجهة الرئيسية، مواجهة | هذي اللي يصوّرها أغلب الزوار |
| 2 | زاوية جانبية (٤٥ درجة) | تبيّن العمق وشكل المبنى |
| 3 | تفصيلة مميّزة قريبة | الشيء اللي ما يتكرر في غيره |

**افعل:**
- صوّر بالنهار، إضاءة واضحة
- عبّي الإطار بالمَعلم نفسه
- صوّر التفاصيل اللي تميّزه: برج، نقش، بوابة، شكل غير مألوف

**لا تفعل:**
- صور ليلية أو ضد الشمس
- ناس أو سيارات تغطي المبنى
- لقطات بعيدة جدًا يصير فيها المعلم نقطة صغيرة
- صور من الإنترنت — **إلا** إذا كانت مرخّصة للاستخدام. الصور المحمية بحقوق
  لا ترفعها؛ هذا مستودع عام

**الحجم:** أقل من 2 ميجا للصورة. الأمر ينبّهك لو فيه صورة أكبر. صوّر بجودة
عادية مو أعلى جودة، أو صغّرها قبل ما ترفعها.

---

## ليه هذا مهم

معلم بدون صور مرجعية وبدون `visual_markers` **ما يدخل التعرّف إطلاقًا**. يظهر
في الخريطة والقائمة، وله صفحة قصة — لكن الكاميرا ما تدّعي إنها تعرفه.

هذا مقصود. لو أعطينا المطابِق معلمًا ما عنده أي وسيلة تمييز، بيخمّن بالاسم أو
التصنيف — والتخمين الواثق الغلط هو الفشل الوحيد اللي هذا المنتج موجود عشان
يمنعه.

يعني: **كل مجلد تعبّيه بصور، تحوّل معلمًا من "مُدرَج" إلى "يُتعرَّف عليه".**

## ملاحظة للمبرمجين

`npm run photos` هو المصدر الوحيد لحقل `reference_images` في `landmarks.json`.
يمسح `public/landmarks/<id>/`، يرتّب الملفات ترتيبًا رقميًا طبيعيًا، ويكتب
المسارات. الأمر idempotent — شغّله كم ما تبي. حذف الصور من مجلد يحذف الحقل.

`isRecognisable()` في `lib/library.ts` يرجّع `true` إذا كان عند المعلم
`visual_markers` **أو** `reference_images`. و`selectCandidates()` يفلتر عليه،
فالمعالم غير المجهّزة ما تُعرض على التعرّف أبدًا.
